# Колбабот для Android

Установочные файлы приложения [Колбабот](https://kolbabot.ru).

## Скачать

Откройте [релиз 1.0.0](https://github.com/Efreitor2001/kolbabot-android-releases/releases/tag/v1.0.0).

- **RuStore APK** — универсальная сборка для установки на Android.
- **Huawei APK** — универсальная сборка для Huawei AppGallery и установки на Android.
- **Google AAB** — файл для Google Play Console, на телефон напрямую не устанавливается.

Android 8.0 и новее. Интерфейс приложения на русском языке. Для работы нужен интернет.

Приложение использует те же аккаунты и сервер, что сайт. Поддерживает каталог, заказы, рецепты, расчёты, PREMIUM, поддержку, нативную админку и уведомления Google/Huawei.

Этот репозиторий содержит только публичные материалы выпуска. Исходники и служебные карты R8 сохраняются в закрытом репозитории владельца. Здесь нет серверных ключей и закрытого ключа подписи.

Сборка и GitHub Release не означают публикацию или одобрение приложения магазинами. Перед подачей нужно выпустить серверные изменения и проверить доступность страниц приложения и политики на основном сайте. Требования магазинов и ограничения текущей версии указаны в материалах релиза.
