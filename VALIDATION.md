- Быстрый вход: согласия, доступность провайдеров, прямой переход к Google, восстановление незавершённой попытки после пересоздания процесса и исходный срок её действия.

- Кабинет: профиль, подписка, подключения и история в порядке сайта; тесты не выполняют реальные платежи.
- Админка: шапка, вкладки, график и показатели, содержание корзин без служебных полей, списки и редакторы на одной странице, сохранение выбранных категорий/сортов, сохранение пользователя и подтверждение выдачи доступа.

## Условия проверки

Используется отдельный чистый эмулятор `KolbaBot_Parity_API_36`, Android 16/API 36, 1080×2400, density 420. Данные ранее существовавшего эмулятора не удалялись. API в UI-тестах заменён контролируемыми ответами; тест карты запускает настоящий MapLibre/WebGL и читает тестовый PMTiles с Range-запросами.

Снимки эталона строятся из исходных HTML/CSS/шрифтов сайта без изменения их геометрии. Сеть перехватывается тестом, содержимое и видимость задаются фикстурами. При сравнении полноэкранного эталона и приложения учитываются системные отступы Android.

На этой машине публичный `kolbabot.ru` во время проверки не отвечал в пределах тайм-аута. Поэтому фактический вход во внешние аккаунты, боевые данные Ozon, платёж и доставка push из production не считаются подтверждёнными локальными тестами. VK/Mail/OK используют существующий браузерный выбор провайдера сайта; отдельного нативного SDK для них серверный контракт не предоставляет.
