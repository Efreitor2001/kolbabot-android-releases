Импорт и VK-синхронизация

С токеном — импорт и описания из VK. Без токена — только YML/XML. Нужен user token без привязки к IP.

Варианты одной карточки

Чтобы объединить товары, выберите для них одинаковое общее название и сохраните каждый. Цена, вес, метраж, фото и остаток остаются своими у каждого варианта. Очистите общее название, чтобы отделить товар.

Электронная книга

Укажите название книги и сохраните карточку. Загрузите обычную и/или мобильную версию в DOCX или PDF и проверьте тестовый PDF каждой. DOCX преобразуется в PDF, на готовый PDF наносится водяной знак. Для публикации включите «Активно» и сохраните карточку.
