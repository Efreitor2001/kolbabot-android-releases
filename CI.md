# GitHub Actions для Android

Ветка `codex/android-1.0.1` закрытого репозитория `Efreitor2001/kolbabot.ru` содержит этот проект в каталоге `android/`. Workflow `.github/workflows/android-build.yml` запускается при изменении Android в ветках `codex/android-*`.

Сборка использует JDK 21 и Android SDK 37, собирает три debug APK, запускает JVM-тесты, lint и выбранные UI-тесты на эмуляторе API 35. Результаты появляются в артефактах запуска. Эта ветка нужна для Android и не должна сливаться в веб-ветку main без отдельного решения о размещении исходников.

Debug APK подписан тестовым ключом GitHub runner. Для обновления установленного релиза нужны исходный закрытый keystore и его пароли. Файл `kolbabot-signing-certificate.der` из релиза содержит только открытый сертификат и не может подписывать приложение. Release-сборка проекта по-прежнему требует внешний `KOLBABOT_SIGNING_PROPERTIES` и прежний keystore; ключи и пароли не добавляются в Git.
