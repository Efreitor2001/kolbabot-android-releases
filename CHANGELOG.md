# 1.0.1 (3) — 15 октября 2026

Основа: `KolbaBot-AndroidStudio-1.0.0.zip` из приватного выпуска `android-v1.0.0`, загруженный 15 октября в 21:18 МСК. SHA-256 исходного архива: `6dc9a11dd7300845571c293b51b0c01be8ce12aa937efa48989c144a4c750f91`.

## Изменения

- Android 13+: системное разрешение на уведомления запрашивается при первом запуске этой версии, в том числе до входа в аккаунт. Уже выданное разрешение повторно не запрашивается. После отказа автоматический запрос не повторяется; в кабинете доступны повторный запрос и настройки Android.
- Уведомления приложения по умолчанию включены для всех аккаунтов. Старое приглашение после входа убрано; отметка о просмотре этого приглашения не отключает новый режим. После проверенного входа устройство подключается автоматически при разрешении Android и доступном провайдере. Явное отключение в кабинете сохраняется отдельно для каждого аккаунта на устройстве. Выход отсоединяет устройство, сохраняя настройку аккаунта.
- В разделе пользователей, профиле, личных оповещениях, назначении существующего администратора и фильтрах обоих журналов используется один выпадающий список с поиском по имени, логину, почте, телефону и ID. Передаётся ID выбранного пользователя. При ошибке загрузки доступен повтор; первый пользователь автоматически не подставляется.
- Для общего оповещения поле личного получателя скрыто и не попадает в запрос. В фильтрах можно выбрать всех пользователей. Существующая возможность создания нового администратора сохранена.
- Системное разрешение, выбор аккаунта и подтверждённая регистрация устройства проверяются отдельно. Доставка после выхода/смены аккаунта и после ручного отключения остаётся заблокированной локально. Временная ошибка регистрации сохраняет включённую настройку и допускает повтор через WorkManager.

## Проверка и выпуск

Обновлены существующие тесты уведомлений, добавлены изолированные UI-сценарии выбора пользователя. Изменённые контракты сверены с текущим серверным API; изменения серверного кода не требуются. Серверный список ограничен 2000 пользователями; для пользователя вне него доступен поиск по точному ID через существующий endpoint досье.

**Сборка через GitHub Actions:** три debug APK успешно собраны из коммита `b0c212f8764639198517d372f284de096147a459`. Прошли 49 JVM-тестов; lint не обнаружил ошибок (52 предупреждения, 5 подсказок). Все 27 выбранных UI-тестов прошли на эмуляторе Android 15 (API 35). Полный [запуск Actions](https://github.com/Efreitor2001/kolbabot.ru/actions/runs/38801526756) завершён успешно; подробности — в [CI.md](CI.md). Прежняя попытка локальной сборки была заблокирована сетью, после чего сборка перенесена в GitHub.

Подготовлены именно debug APK с отладочной подписью и без R8. Выпуск с прежним ключом подписи и публикация в GitHub Release/магазинах не выполнялись. Без прежнего ключа эти APK нельзя установить обновлением поверх опубликованной версии 1.0.0.

На машине с Android SDK 37 и JDK 21:

```powershell
.\build.ps1 -Check
.\build.ps1 -Check -DeviceTests
.\build.ps1 -Release
```

Последняя команда требует прежний внешний ключ подписи. Архив ключей и паролей не содержит. После сборки проверьте чистый запуск с гостем, разрешение и отказ Android, вход/выход/смену аккаунта, отключение в кабинете, все места выбора пользователя и отправку личного оповещения на тестовый аккаунт. GitHub Release и магазины этим архивом не обновлены.
